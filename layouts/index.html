01The grid

The top margin is not one number, and that is the point.

The written 6% / 7.5% flat was a real decision flattened to a constant. What the decks actually do is vary the top margin by what leads the slide, and that variation is the mechanism that guides the reader: a kicker is small and quiet so it can sit high, because it is not the message; a statement needs air above it to land. Give the title the kicker's margin and the slide top-loads — the composition loses the breath that makes the rest of the system work. So the three steps stay, snapped to one unit so every value is a multiple (ch02, Fixed).

Every value is a multiple of one unit — 1.3333% of slide height — so the slide grid obeys the same one-base-unit rule as the spacing scale. The footer band and the largest top step are both ten units, so a slide led by a full-bleed element sits in a centred band. That is a consequence of the unit, not a separate rule.

Why the footer band is on every slide

Reserved on EVERY slide, covers and closers included. The band is not there because a number is printed in it — it is there because in a physical room the bottom of the screen is the hardest place to read: heads sit in the sightline. That reason does not change when the number does, so it is one grid, not two (ch12, readability from the back of the room).

02The twelve

Each one is an arrangement of components that already exist. None of them defines a component of its own — if a layout needed one, that would mean the component layer was missing something, not that the layout was special.
