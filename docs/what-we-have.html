How to read a row. “In the codebase as” is the actual class in the generated stylesheet — if it were not really there, this page would say so, because the script looks it up rather than taking my word for it. “Logic” is the rule that says why the component exists and when you may deviate. A component with no rule is a habit; a rule with no component is an intention.

Two notes under a row name. Produced by the router means you can hand that component raw content and get the finished thing back, rules applied. Checked by names the script that fails the build if the rule is broken — a rule nothing checks is a rule that will quietly stop being true.

03The other direction

An audit that only looks one way misses the thing that actually causes drift: stuff in the system that nobody asked for. So this checks backwards too.

In the codebase, not in any reference file

Everything in the stylesheet traces back to a reference file.

Rules with nothing on this page enforcing them

Rules in the rule set that no component on this page claims. Most govern process rather than appearance, which is fine — but each should be able to name what enforces it:

  • NC-DGM-01 — Do not build a generic diagram kit of nodes and connectors. Name the job — bound, relate, decompose, sequence, diverge, converge — and use a named for
  • NC-DOC-02 — A4 for UK submissions.
  • NC-DOC-03 — Document title, author and one declared language set in properties.
  • NC-EVI-03 — No published figure rests on fewer than three contributing units. Apply secondary suppression.
  • NC-EVI-05 — Apply the suppression threshold to the planned sample BEFORE fieldwork is scoped, and state at proposal stage what the design will let you say.
  • NC-LAY-03 — Keep core information in a simple reading order. Single-column for long-form where practical.
  • NC-PKG-01 — One source per number, named, wherever a figure appears in more than one artefact. Reconcile across the pack before submission, as a step.
  • NC-PKG-02 — Where artefacts disagree, date them and name the most recent as the candidate truth. Never report an unresolved contradiction and hand the job back.
  • NC-PRS-01 — Reading order set explicitly, on every slide. Placeholders authored in reading order in the master.
  • NC-PRS-02 — Every slide carries a unique descriptive title. It may be hidden or off-canvas; it may not be absent.
  • NC-PRS-04 — No text box sized to its text.
  • NC-SYS-01 — State where the current version lives, in the system itself. Name the canonical location once; treat every other copy as derived.
  • NC-SYS-02 — Quote the line every finding rests on, or mark the finding as inference. Report an absence as a different class of claim from a quotation.
  • NC-XLS-01 — Spreadsheets are models: real tables, formulas from one assumptions sheet, freeze panes, no merged cells in data.

04What this tells us

The document layer is solid

Grounds, type, containment, the section header, pull quotes, breakout stats, tables, evidence furniture and the core charts are all built and all carry their rule. That is the part you use in a report, a web page or an evaluation — and it is the part that was missing when the system was built from the slides outwards.

The slide layer is the hole

Twelve layouts exist as working markup in your reference file and in the repo’s older layouts/ folder, but nothing generates them from the tokens, so nothing checks them. They are the last place a hand-set value can hide.

Four chart forms are named and not built

Pie, line, range bar and the not-collected marker are all specified in charts v1.4 and the style guide. Until they exist, anyone needing one will reach outside the system — which is exactly how a system starts to leak.

Everything on this page is checked against the Nightlife Culture Style Guide v1.4 and the Decision Book at build time. If a class is renamed or a rule removed, this page changes with it.
