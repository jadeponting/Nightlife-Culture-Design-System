How to read a row. “In the codebase as” is the actual class in the generated stylesheet — if it were not really there, this page would say so, because the script looks it up rather than taking my word for it. “Logic” is the rule that says why the component exists and when you may deviate. A component with no rule is a habit; a rule with no component is an intention.

Two notes under a row name. Produced by the router means you can hand that component raw content and get the finished thing back, rules applied. Checked by names the script that fails the build if the rule is broken — a rule nothing checks is a rule that will quietly stop being true.

04What this tells us

The document layer is solid

Grounds, type, containment, the section header, pull quotes, breakout stats, tables, evidence furniture and the core charts are all built and all carry their rule. That is the part you use in a report, a web page or an evaluation — and it is the part that was missing when the system was built from the slides outwards.

The slide layer is generated, not yet contracted

Twelve layouts are generated from the tokens by layouts/build_layouts.py. Their slot contracts in foundations/layouts.json — word limits, anchors, permitted grounds — are recorded but not yet read by any script, so nothing checks them.

The chart set is built

Pie, line, range bar and the not-collected marker, specified in charts v1.4 and the style guide, were built in v1.2 and are in the component library.

Everything on this page is checked against the Nightlife Culture Style Guide v1.5 and the Decision Book at build time. If a class is renamed or a rule removed, this page changes with it.
