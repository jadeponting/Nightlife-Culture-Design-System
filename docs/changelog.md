# Changelog

## v1.0 — August 2026

First version of the system as an enforceable repo rather than a written guide.

**Added**
- `contracts/layouts.json` — twelve slide layouts with slot contracts, word limits, required
  elements, permitted grounds and vertical anchors.
- `contracts/rules.json` — global colour, grid, composition, typography, chart and footer rules.
- `system/slides.css` — the slide system, with the anchor rule enforced in CSS and a visible coral
  warning when `data-anchor` is missing.
- `tools/validate.py` — validator. Standard library only.
- `tools/contrast.py` — WCAG contrast checker.
- `templates/deck.html` — a twelve-slide reference deck that passes validation.
- `AGENTS.md` / `CLAUDE.md` — the contract for any AI agent working in this repo.
- `golden/` — reference renders.

**Decisions**
- The anchor is a **contract field, not a styling choice**. Authors do not pick it. Implicit
  top-anchoring was the single largest cause of weak slides in earlier attempts.
- Ground classes carry their own text, kicker and title colours, so the colour law cannot be
  forgotten by setting a colour by hand.
- `maxBlocks` must be at least the number of slots a layout declares — enforced by
  `--check-contracts`, after the first draft shipped three layouts that contradicted themselves.
- Plain HTML and CSS only. No framework, no build step, no second source of truth.

## v1.1 — 16 August 2026

The system stops being a set of styles and becomes a set of decisions.

**Added**
- `foundations/tokens.json` and `foundations/rules.json` — the single source for every value and
  every rule. Nothing downstream is hand-written.
- `checks/build.py` — generates `foundations/nightlife-culture.css` from those two files.
- `checks/validate.py` — fails the build on a broken Fixed rule.
- `checks/check_stamps.py` — every derived artefact records the digest of its sources and fails
  when they diverge, so a stale copy cannot pass as current (ch18).
- `components/library.body.html` + `components/build_library.py` — the component library, built in
  two forms: a linked form that cannot go stale, and a self-contained form for sending.
- `components/route.py` — **the router.** Content in, component out. Asks the decision stack in
  order, and can refuse.
- `docs/build_routing.py` → `docs/how-the-logic-works.html` — the routing explainer. Generated by
  running the router, so it cannot describe behaviour the system does not have.

**Decisions**
- Components are grouped by **the job they do**, not by what they look like — six families:
  structure, argument, containment, evidence, punctuation, reference. This is what lets the same
  set serve a deck, a web page, a dashboard and an evaluation report.
- **The edge treatment is the instruction.** Top rule, left rule, flyer outline, band and hairline
  each carry a fixed meaning (v1.4 §09), so a container is chosen by asking what the reader is
  being told to do — never by eye.
- **The router can stop.** Factual integrity sits above brand expression in the stack, so evidence
  that fails the comparability gate or a plausibility test never reaches a colour decision. Bad
  data is not quietly repaired; it is refused with a reason.
- **Typed capitals are normalised at the source**, including single shouted words and shift-key
  artefacts, and re-applied as a format — so the underlying string stays readable to search,
  copy-paste and a screen reader.
- Charts stack their rows below 30rem. A bar earns its place by encoding length from zero; a
  squeezed track still looks like a chart while no longer being readable as one.
- Every string replacement in a build script asserts that it matched, after one silently wrote a
  file and reported success.

## v1.2 — 16 August 2026

The five waves, closed. 126 of 126 components built, with the rule attached.

**The slide grid — decided**
- Side margins 5.25%. Top margin varies by what leads the slide: 4% for a kicker,
  6.667% for a title, 13.333% for a full bleed. All four are multiples of one unit
  (1.3333% of slide height), so the slide grid obeys the same one-base-unit rule as
  the spacing scale.
- The flat 6% / 7.5% in v1.4 was a real decision flattened to a constant. The variation
  is the mechanism that guides the reader: a kicker is small and quiet so it can sit
  high; a statement needs air above it to land. Give the title the kicker's margin and
  the slide top-loads.
- The footer band is 13.333%, reserved on **every** slide, covers and closers included.
  Not because a number is printed there — because in a room the bottom of the screen is
  the hardest place to read, heads sit in the sightline. That reason does not change
  when the number does, so it is one grid, not two.
- A consequence, not a separate rule: the band and the largest top step are both ten
  units, so a slide led by a full-bleed element sits in a centred band.

**Added**
- `checks/build_slides.py` → `foundations/nightlife-slides.css`. The slide layer is a
  CONTEXT, not a component set: it sets the base the components scale against, plus the
  arrangements that only exist on a slide.
- `layouts/build_layouts.py` → `layouts/index.html`. Twelve layouts generated from the
  tokens. Change the grid once and all twelve move.
- Pie, line, range bar, the not-collected marker, the comparability flag and the
  illustrative flag — all specified in charts v1.4 and previously unbuilt.
- The remaining HTML surfaces: code, pre, dl, small, details, abbr, mark, sup/sub, kbd.
- `docs/status.py` — one definition of "complete", shared by the audit and the plan, so
  the plan cannot list work the audit counts as done.
- Eight new checks in the validator: non-uniform scaling, chart packaging, illustrative
  flags, one breaker per surface, tables on slides, the caps floor, repeating table
  headers, band-and-rule.

**Decisions**
- **A layout arranges components; it never defines one.** If a layout needs something
  new, the component layer is missing it. Components born inside slides is exactly how
  the system drifted the first time.
- **Colour is a modifier, never baked into a component** — otherwise a seventh accent
  means a seventh component.
- **Focus rings are exempt from the hard-outline rule** and required, not optional.
  Containment v1.3 names focus states as one of the four places the 3:1 threshold
  genuinely applies.
- **Full-bleed grounds bleed; their text does not.** An accent block or ink strip runs
  to the edge, but the words inside it stop at the footer line for the same reason
  everything else does.

**Fixed while building**
- The audit's selector check matched prefixes: `.ground-blue .nc-quote` passed on the
  strength of `.ground-blue .nc-quote .a`. Seventeen components read as complete when
  only a child was defined.
- A brace-free 200KB page made the CSS-block scan backtrack for sixteen seconds and
  find nothing. The stylesheet is now resolved once, from `<style>` blocks or the
  linked files.
- Two checks counted class names in running text as markup, so the audit page failed
  its own rules for describing them. They count real class attributes now.
- Off-scale padding (0.1em, 0.15em, 0.3em, 0.35em) in the new HTML surfaces, snapped
  to the scale.
- Charts did not invert on a dark ground — an ink-on-ink track at 7% is invisible.
- Slide titles in the layout catalogue were real headings, building an outline of
  twelve h1s inside one document. They are specimens there; in a live deck the slide
  title is a heading (NC-PRS-02).

## v1.3 — 16 August 2026

Answering the read-only audit of 16 August. Every finding was re-executed against the working
tree before acting on it; the contrast arithmetic was recomputed from sRGB relative luminance
rather than taken on trust. Every number in the audit reproduced exactly.

**The colour law — corrected everywhere, and made checkable**
- `AGENTS.md` said *"every accent is a black-text surface; every ground is a white-text surface —
  if you remember nothing else, remember that."* It is false for two of the four grounds: white
  on chalk is 1.1096:1, white on white is 1.0000:1. Being memorable made it worse, because that
  is the line an agent carries into a file.
- NC-COL-01 rewritten: accents take ink text; each ground declares its own. Both copies in
  `AGENTS.md` replaced with the measured table.
- Every ground now carries its own `--nc-on` text token. There is deliberately no single
  `--nc-on-ground`: one value spanning every ground is what let the false sentence look true.
- **NC-COL-01 is now a check.** `checks/validate.py` fails the build on white text over a light
  ground, in CSS or inline. Proven to fire on a test file.

**Colour data — every ratio names its pairing**
- Charcoal was filed under grounds. It is a text colour, and its published 12.41 is charcoal text
  on chalk — not white text on charcoal (13.77) and not against ink (1.41). Moved to
  `colour.textColours`, with all three figures written out.
- The accents declared `textOn: "black"` while publishing ratios measured against ink. Ink is what
  the CSS sets; the label was what was wrong. Corrected, and every ratio now carries an `against`
  field so a number can never again be read against the wrong pairing.

**NC-BRK-01 — the staleness check accepted the stale version**
- The pattern was `r"v1\.4|Style Guide v"`. The second alternative matches any version string, so a
  file declaring "Style Guide v1.0" passed a check built to catch exactly that.
- It now reads the current version from `tokens.json` and fails on a declared version that is not
  the current one. Tightening it again is a data edit, not a code edit. Proven to fire.

**NC-TYP-15 — fallbacks were named but not corrected**
- Zero occurrences of `size-adjust`, `ascent-override`, `descent-override` in the repository.
  Embedding answers "the font is missing"; it does not answer "the font has not arrived yet", or
  the machines that cannot embed at all.
- Overrides computed from the actual OS/2 and hhea tables of the eight `.woff2` files against
  Arial: Archivo 101.44%, Archivo Black 101.82%, Inter 105.27% size-adjust, with matching
  ascent and descent. The stacks name the corrected face. New rule, and a check.

**Table cells finally got their leading**
- 59 scoped `line-height` declarations across the stylesheets and none on a table. Cells inherited
  1.6 from `.nc-doc` against ch03's 1.25–1.35. GAP-01 was raised about exactly this class and the
  fix had been applied everywhere except it. `.nc-table` 1.3, `.nc-slide .nc-table` 1.25.

**The first generation archived**
- `tokens/`, `system/`, `contracts/rules.json`, `tools/`, `templates/`, `components/components.css`
  and the root `index.html` moved to `archive/2026-08-16-pre-foundations/` with a note naming what
  each one got wrong. That closes, by removal rather than by patch: the second validator, the four
  resurrected grey tokens, `#6A6A6A` in thirteen files, ten live-type wordmarks, the CVD claim that
  contradicted its own sibling, and a personal email address in the file everyone was told to copy.
- **`contracts/layouts.json` was NOT archived.** Moved to `foundations/layouts.json` unchanged —
  slot contracts, word limits, block budgets, permitted grounds and the anchor per layout. It is
  the one thing the old generation held that the new one had never replaced. Recorded now,
  enforced next: wiring it into the layout generator and the validator is an open job.

**The instruction files**
- `AGENTS.md`, `CLAUDE.md` and `README.md` all declare v1.4 and a date. `AGENTS.md` had no version
  at all while governing every model, and `README.md` still named v1.0 as source of truth.
- One validator named: `checks/validate.py`, invoked by `build.py`.


## 16 August 2026 — the disclosure learns where things came from

**The dropdown under each specimen now answers the question it was asked**
- It showed the markup. It did not show where the styling CAME from, so a specimen drawn by hand
  and a specimen built from the codebase read identically — which is the one thing the disclosure
  exists to tell apart.
- `components/provenance.py` resolves every class in a specimen to the file, the line and the
  section that defines it, and names the generator that wrote that file. Nothing is typed. The
  markup is read off the render; the definition site is read off the stylesheet.
- Anything the specimen styles from inside its own markup is flagged, with a word as well as a
  colour, and the count sits on the summary where it is read without opening anything.
- Three severities: type or raw colour or a hand-set measurement in the markup is FLAGGED; a
  token used in the markup with no class behind it is NOTED; a percentage width carrying a datum
  is DATA, because a bar's length IS the number and belongs in the markup.

**What it found on its first run: 34 flags across 3 of 19 specimens — and 32 of them are one thing**
- The type scale is not a component. Six roles in `tokens.json`, no class for any of them, no
  document sizes at all — `type.sizes.document.scale` says UNDECIDED — and five invented em sizes
  drawn into the library markup, looking settled. Logged as gap 9. Not fixed: not mine to choose.

**`.nc-prov` was defined twice and nothing could see it**
- The evidence-provenance chip, and then a provenance table four sections later. The later one won.
  Every cell rendered white on white. Validator passed, coverage passed, stamps matched.
- Renamed to `.nc-origin`, and `check_coverage.py` now reports a class defined twice where the
  second definition re-sets a property the first one set. `@media` overrides excluded. It reports
  rather than fails: there is no rule, and four current cases look deliberate. Logged as gap 10.

**Two defects fixed in the disclosure while building it**
- The `<summary>` marker was the browser default, in the one component whose job is to show that
  nothing is left to a default (NC-DOC-08). It is now a word — SHOW / HIDE.
- The flag tag was pink on white: 2.58:1 at 11px caps. Now ink, with the pink rule on the left edge
  carrying the colour signal.

**A selector defines its subject, not every dot in it**
- `.nc-slide .cv` defines `.cv`. Reading every class in a selector is how seventeen components once
  read as built when only a child of each was defined. The resolver reads the last compound of each
  comma-separated part and nothing else.
