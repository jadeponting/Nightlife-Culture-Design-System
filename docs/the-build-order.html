No new asset types until this list is empty.

Word, PowerPoint and Excel templates all consume the component layer. Building them while the layer has holes in it means the holes get filled ad hoc, in three formats, by whoever is closest to the deadline — which is exactly how the first version drifted. Every one of these is a place a hand-set value can enter the system.

The order is not preference. It runs from work that needs no decision, through work that needs a check written, to the one wave that waits on you.

03What is still open

The grid is settled

Settled 16 August 2026: 5.25% side margins, a three-step top margin (4%, 6.667% or 13.333% by what leads the slide) and a 13.333% footer band, all multiples of one unit. Recorded in foundations/tokens.json and NC-LAY-06. The twelve layouts are generated against it.

What is not done: the slot contracts in foundations/layouts.json are recorded but no script reads them, so word limits and anchors are not yet checked.

Seven contradictions inside Style Guide v1.4 are also still open — butter as Series 4, title lines two or three, coverage 55 or 70 per cent, full-bleed accent grounds, logo minimum 90px or 1.5%, logo in running headers, eight tokens or ten. None of them block a wave; all of them are recorded rather than quietly resolved.
