The one colour rule

Every accent is a black-text surface. Every ground is a white-text surface. No exceptions. Use the .nc-on-ground / .nc-on-accent utilities above rather than picking text colour by eye.

The caps rule: Display/H1/H2 are always tracked and never used below 16px on screen or for more than ~8 words. H3 and below stay sentence case — that boundary is enforced by which class you reach for, not a judgement call each time.
