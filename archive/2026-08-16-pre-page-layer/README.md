# Superseded — five hand-written page stylesheets

Archived 16 August 2026. Replaced by the page layer in `foundations/nightlife-culture.css`
and the single page builder at `docs/sheet.py`.

These five files were the last hand-authored thing in a generated system. Each one carried its
own masthead, measure, kicker, standfirst, note and specimen frame — and because nothing
governed them, they disagreed. Three declared an ink masthead and two declared blue, in a
system whose stated purpose is that this cannot happen.

Every visual defect found in the 16 August review lived in these files rather than in the
components: the mastheads, the specimen frame that overrode a dark-ground specimen, the note
text that fell below the size floor on a dark ground.

The failure underneath was not the CSS. No rule existed for a masthead ground, and rather than
reporting the absence, an answer was invented five separate times. That is logged as gap 6 in
`docs/gaps.md` and upstream as GAP-30 in the decision-book register — the Book has no rule for
page furniture either.

Kept for reference. Nothing derives from them.
