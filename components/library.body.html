The rhythm is not a size. Each heading carries three times the space above it that it carries below, so it attaches to what follows rather than floating between blocks — ch03. That is why the gaps above these headings are uneven and deliberate.

Leading is scoped, not one number. Display 1.02–1.1 · H2/H3 1.15–1.25 · running prose 1.5–1.6 · table cells 1.25–1.35 · captions 1.3–1.4 · statistic blocks 1.0–1.1, because a number is not text · lists 1.4–1.5. The 1.5 floor is a running-prose rule and applying it as a blanket is a category error.

18The page layer

The furniture every sheet needs. This did not exist until now — the system had ninety components and nothing for the page around them, so each sheet was hand-authored. Five separate stylesheets, none governed, and they disagreed: three declared an ink masthead and two declared blue.

Why this section exists

Every visual defect found in the 16 August review lived in the page furniture, not in the components — the mastheads, the frame that overrode a dark-ground specimen, the note text that fell below the size floor. The components were right the whole time. The page around them was hand-drawn each time, and nothing checked it.

The build now refuses if any folder contains its own stylesheet. There is one page builder, and it is the only place page furniture is decided.
